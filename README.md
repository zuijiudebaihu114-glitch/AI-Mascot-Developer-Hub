# AI-Mascot-Developer-Hub
AI Mascot &amp; Developer Hub — интерактивный ИИ-помощник с озвучкой ответов и живыми эмоциями маскота. Приложение распознает вежливость и грубость (с блокировкой за спам), хранит базу знаний с закрытым разделом для Студсовета и включает панель разработчика. Работает автономно в браузере с сохранением истории и настроек в localStorage.
